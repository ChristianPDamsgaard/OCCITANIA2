Scripts that generate hand-made focus trees for this mod (not loaded by the game).

    python tools/gen_spc.py .   # Aragon: SPC_NF.txt, SPC_focus_ideas.txt, SPC_focus_l_english.yml
    python tools/gen_gre.py .   # Greece: GRE_NF.txt, ideas, Greek Uprising event, uprising OOBs, localisation
    python tools/gen_byz.py .   # Byzantium (X09): X09_NF.txt, ideas, characters, byzantium event, Varangian OOB, localisation

Edit the scripts, not the generated files, then re-run from the mod folder.
